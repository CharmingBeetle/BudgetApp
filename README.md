# Miss Capital Budget App

## 📚 Project Overview
This BudgetApp is an short project developed as part of the Code First Girls JavaScript course. It demonstrates fundamental JavaScript concepts through a practical budget tracking application. 

## 🌐 Hosting Link
[Miss Capital Budget App](https://misscapital.netlify.app)

## 🎓 Learning Objectives
- Implement JavaScript for dynamic content manipulation
- Utilize DOM manipulation techniques
- Practice responsive web design principles
- Create simple calculations for budget tracking
- Build form handling and input validation
- Apply event listeners

## ✨ Features Implemented
- Basic expense tracking functionality
- Income entry and categorization
- Simple data visualization with JavaScript
- Form data handling and validation
- Responsive design for mobile and desktop viewing

## 🛠️ Technologies Explored
- HTML5 for structure
- CSS3 for styling
- JavaScript for interactivity

##  How to Run the Project
1. Clone the repository:
   ```
   git clone https://github.com/CharmingBeetle/BudgetApp.git
   ```
2. Open `index.html` in your browser to view the application.
